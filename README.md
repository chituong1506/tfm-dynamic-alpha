# tfm-dynamic-alpha

Dynamic-alpha object-weighted transaction fee mechanism for parallel execution blockchains.

Based on: Wadhwa, Yaish, Zhang, Nayak. "Perils of Parallelism: Transaction Fee Mechanisms
under Execution Uncertainty", USENIX Security 2026.

## Layout
- mechanism/  mechanism specification
- proofs/     formal proofs (LaTeX)
- sim/        simulator, tests, configs
- results/    experiment outputs
- paper/      manuscript
- docs/       notes, decisions, assumptions
